# Blog Didáctica de las Ciencias

Blog realizado para la asignatura de Comunicación y Didáctica de las Ciencias. Elaborado por **Juan Pablo Montenegro Erazo** y **Juliana Ruiz Montoya**.

## Enlace de acceso

La página web se encuentra publicada a través de GitHub Pages en la siguiente dirección:

https://juan-pablo-montenegro.github.io/Pagina_Comunicacion/

## Estructura del repositorio

- `index.html`: Documento principal con el texto del artículo, esquemas vectoriales interactivos y figuras del estudio.
- `styles.css`: Hoja de estilos para la maquetación editorial y el soporte de tema oscuro y claro.
- `script.js`: Lógica de interacción del esquema galáctico, pestañas de comparación de simulaciones y ampliación de imágenes.
- `assets/images/`: Figuras extraídas del artículo original y material gráfico de apoyo.
